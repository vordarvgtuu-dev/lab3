# Домашнее задание к работе 3

## Условие задачи
Написать и отладить программу расчета сопротивления двух последовательно и параллельно соединенных резисторов (сопротивления резисторов задается пользователем).
1. **Начало.**
2. **Настроить вывод консоли на русский язык:**
- `SetConsoleOutputCP(65001)` установить кодировку UTF-8 для корректного отображения русского текста.
3. **Объявить переменные:**
   - `r1` — сопротивление первого резистора (Ом).
   - `r2` — сопротивление второго резистора (Ом).
4. **Ввести исходные данные:**
Вывести приглашение на ввод первого резистора.
   - Считать значение `r1` с помощью `scanf`.
Вывести приглашение на ввод второго резистора.
   - Считать значение `r2` с помощью `scanf`.
5. **Вывести результаты расчетов**
   - Вывести значение сопротивления при последовательном соединении с расчетом `r1 + r2`
   - Вывести значение сопротивления при параллельном соединении с расчетом `(r1 * r2) / (r1 + r2)`
6. **Конец**
     
## 2. Реализация программы

#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <windows.h> // не работает #include <locale.h>

int main() {
	SetConsoleOutputCP(65001);
	float r2, r1;
	printf("Программа расчета сопротивления двух последовательных и параллельных резисторов, которые не равны нулю:");

	puts("\n\nВведите значение первого резистора(в Ом):"); // 1ое число
	scanf("%f", &r1);

	puts("\nВведите значение второго резистора(в Ом):"); // 2ое число
	scanf("%f", &r2);

	printf("\nОтвет:\nСопротивление при последовательном соеденение равно %.2f Ом \nСопротивление при параллельном соеденение равно %.2f Ом\n", r1 + r2, (r1 * r2) / (r1 + r2));
	return 0;
}
